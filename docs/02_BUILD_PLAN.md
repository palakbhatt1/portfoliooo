# 4-Hour Build Plan

Rule: content > code. Recruiters skim case studies, not your animations.

| Time | Task | Done when |
|---|---|---|
| 0:00 – 0:20 | Scaffold Astro + Tailwind + MDX, push to GitHub, connect Vercel | Blank site live on a URL |
| 0:20 – 0:45 | Design tokens: 1 font, 2 neutrals + 1 accent, spacing scale, base layout, nav, footer | Layout renders on desktop + mobile |
| 0:45 – 1:30 | Home page: hero, 3 project cards, short about, contact | Page complete with real copy |
| 1:30 – 2:45 | **Case study template + flagship case study** (see 03) | One full case study live |
| 2:45 – 3:15 | Second case study (shorter) + about page | Two case studies live |
| 3:15 – 3:40 | Mobile pass, alt text, meta tags, OG image, favicon | Lighthouse ≥ 90 across the board |
| 3:40 – 4:00 | Final deploy, test all links, send to one person for a 2-min skim | Shipped |

## Cut list (if you fall behind, drop in this order)
1. Third case study
2. About page → fold into home
3. OG image
4. Anything animated

## Non-negotiables
- Resume PDF download button
- LinkedIn + email visible on every page
- Every case study opens with a one-line outcome
- Works on phone (recruiters open links on mobile)
